# ALYA PİLATES — Ders Takip

Tek sayfalık uygulama (`index.html`). Veriler Supabase'de (`docs` tablosu), giriş e-posta + şifre ile.

- **Yayın:** GitHub Pages (Settings → Pages → Branch: main, / (root))
- **Veritabanı:** `supabase.sql` Supabase SQL Editor'da bir kez çalıştırılır.
- **Güncelleme:** Yeni `index.html` gelince depoda *Add file → Upload files* ile aynı adla yükle (üzerine yazar). Pages 1-2 dakikada yenilenir.
- **Sürüm:** `index.html` içindeki `APP_VER` ile `version.json` aynı olmalı; uygulamadaki "Güncelle" butonu yeni sürümü `version.json`'dan anlar.
- **Yedek:** Yönetici paneli → Şimdi yedekle (Excel). Pilates ve Ana Branşlar birlikte; Excel'de düzenlenip "Excelden yükle" ile geri alınabilir.
